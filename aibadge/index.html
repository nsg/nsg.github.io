Self-reported repository disclosure

How I use AI in a project.

Disclosure beats guesswork. These badges show how generative AI contributed to my repositories. Some people prefer to avoid AI-produced code or assets, which is entirely fair. As human and machine work become harder to distinguish, the labels make the origin of my commits clearer for anyone who cares.

They describe process, not quality. Human-written code can be poor and AI-written code can be excellent. Whether I wrote it, generated it, or paid someone else to implement it does not determine whether it is well designed, tested, reviewed, secure, and fit for purpose.

At every level I may shape the architecture and direct the work. Vibe-coded means I do not read the source, not that quality control is absent. Agents review one another, while tests and workflows verify results and sometimes catch corner cases I would miss.

I omit provider-specific co-author tags because most contributions mix agents, models, and coding harnesses. They delegate work, review one another, and exchange feedback, so the tool making the final commit rarely represents the whole effort. Unless stated otherwise, assume each task went to the best-suited system.

AI-assisted

I used AI for small, contained parts of this project. It acted as a tool to accelerate or automate parts of my workflow, but did not produce substantial sections of the work. Most of the project was written manually by me, and I have personally reviewed and audited every line, including anything generated by AI.

AI writes and maintains most of the code. I may inspect parts of it and remain involved at the architectural level, but the implementation is predominantly AI-produced. Much of my work is on the surrounding system: the rules, testing approach, agent reviewers, and tooling that guide how the AI works.

04Limited human review

Vibe-coded

I shape the architecture and the system around the agents, including the tooling, rules, guidelines, guardrails, structure, component boundaries, and data flow. I do not read the source code at all. I mainly use this label for small, one-off projects built for myself, and rarely for software intended for others, where I want human review of the code before release.
